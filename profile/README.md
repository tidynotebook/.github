# tidy notebook

tidy notebook is a self-hosted Markdown notes application. A note is a plain
Markdown file in a folder that you choose. Typing writes a draft on your
device. Save creates one version on your server.

- **Plain files.** You can export all your notes as Markdown at any time.
- **Explicit save and history.** Each save is one version. History restores
  any version.
- **Works offline.** The application sends a queued save when the connection
  returns.
- **Yours to run.** One Compose file, encrypted backups, no telemetry, and no
  license key.
